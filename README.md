# Автоматика для гидравлического маслопресса

Система плавного разгона давления для достижения максимального выхода масла и экономии времени, версия 2.6 с дисплеем TFT 320x240

Полностью автоматизированный процес после закладки семян в бочонок -- нажал кнопку "Старт" и вернулся в конце цикла

- 10 предустановленных программ для оптимального отжима
- 4 программы "Стандарт" на 40, 60, 120 и 180 мин: плавный подъём давления и удержание на максимальном значении 4, 20, 80 и 140 мин соответственно
- До 20 программ отжима
- До 20 диапазонов давлений
- Выбор культуры для отжима на экране при помощи энкодера-крутилки
- Контроль текущего давления на отдельном индикаторе
- Просмотр общего времени отжима для каждой культуры (однократное нажатие на кнопку энкодера)
- Просмотр всех диапазонов давлений для выбранной культуры (длительное нажатие на кнопку энкодера на экране времени отжима)
- Просмотр графика отжима выбранной культуры (однократное нажатие на кнопку энкодера на экране с диапазонами)
- Сигнальный светодиод по окончании процесса отжима. Мигает 100 раз, выключается кнопкой "Стоп"
- Звуковой сигнал при включении, старте и окончании программы отжима
- Функция продолжения отжима с любого значения давления (удержанием кнопки "старт")
- Защита от "холостого пуска", когда рукоятка распределителя в нерабочем положении

- Веб-интерфейс, в котором можно посмотреть и изменить настройки отжима для любой культуры, добавить новую культуру, удалить любую и восстановить "заводские" настройки
- Возможность настроить время включения аварийного режима, либо вовсе его отключить
- Выключение/выключение звукового сигнала
- Выбор датчика давления 60/70 МПа
- Управление отжимом любой культуры из web-интерфейса: старт/стоп, запуск с любого диапазона с таблицей процесса
