# Автоматика для гидравлического маслопресса c контролем температуры

Система управления гидравлическим прессом с подогревом для варки янтаря под давлением

![янтарь снаружи](https://github.com/user-attachments/assets/8535df5b-11f1-4986-a84e-30a7c18cd3b5)

Полностью автоматизированный процес - нажал кнопку "Старт" и вернулся в конце цикла

Контроллер измеряет при помощи датчиков температуру и давление, управляет исполнительными механизмами тремя твердотельными реле

Контроллер поддерживает заданные давление и температуру на каждом этапе заданное время. Если на любом из этапов давление указано "0", то происходит сброс давления подачей сигнала на управляющее реле сброса до тех пор, пока давление не достигнет нуля.

Все значения давлений и температуры можно изменять через веб-интерфейс 

- Основной экран с настройками WiFi, отображения параметров программы, процесса программы, окончания и аварийного экрана
- Контроль текущего давления и температуры на отдельных индикаторах
- До 30 программ 
- До 30 диапазонов давлений и температуры
- Выбор программы на экране при помощи энкодера-крутилки
- Прокрутка параметров программы
- Просмотр общего времени каждой программы и времени каждого этапа
- Сигнальный светодиод по окончании процесса отжима. Мигает 100 раз, выключается кнопкой "Стоп"
- Звуковой сигнал при включении, старте и окончании программы отжима
- Светодиоды, дублирующие включение реле подачи давления, температуры и сброса давления
- Веб-интерфейс, в котором можно посмотреть и изменить настройки любой программы, добавить новую программу, удалить любую и восстановить "заводские" настройки
- Возможность настроить время включения аварийного режима, либо вовсе его отключить
- Выключение/выключение звукового сигнала
- Выбор датчика давления 60/70/80/100 МПа
- Управление процессом любой программы из web-интерфейса
